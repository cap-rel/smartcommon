# GlobalState

Le store Redux (Redux Toolkit) monté par `<Provider>`, à travers
`ReduxProvider`. smartcommon y range une seule tranche, `global`, qui
reflète les états globaux gérés par `useGlobalStates` (voir
`Hooks/useGlobalStates`). Une application y ajoute ses propres tranches
par la configuration.

```js
import {
  reducers,
  globalReducer,
  setGlobalStates,
} from "@cap-rel/smartcommon";
```

## Symboles exportés

| Symbole | Signature | Rôle |
|---------|-----------|------|
| `reducers` | `{ global: globalReducer }` | Reducers montés d'office dans le store. |
| `globalReducer` | reducer | Tranche `global`, état initial `{}`. |
| `setGlobalStates` | `(payload) => action` | Remplace toute la tranche `global` (type `global/setGlobalStates`). |

## Ajouter ses propres tranches

`ReduxProvider` crée le store avec `{ ...reducers, ...config.globalState.reducers }`.
Une application déclare ses tranches dans la configuration de `<Provider>` :

```jsx
import { createSlice } from "@reduxjs/toolkit";
import { Provider } from "@cap-rel/smartcommon";

const cartSlice = createSlice({
  name: "cart",
  initialState: { lines: [] },
  reducers: {
    addLine(state, action) { state.lines.push(action.payload); },
  },
});

const config = {
  api: { prefixUrl: "/api.php/" },
  globalState: { reducers: { cart: cartSlice.reducer } },
};

<Provider config={config}>
  <App />
</Provider>;
```

Les composants lisent ensuite `state.cart` avec `useSelector` de
`react-redux`, comme dans toute application Redux.

## La tranche `global`

`useGlobalStates` garde les états globaux (en mémoire, `localStorage` ou
`sessionStorage`) et recopie leurs valeurs dans `state.global` par
`setGlobalStates` à chaque changement. Lire ces valeurs par
`useGlobalStates` plutôt que par `useSelector(state => state.global)`, et ne
pas envoyer `setGlobalStates` soi-même : l'appel suivant du hook
écraserait la valeur.

## L'utilisateur connecté

Il n'est pas dans le store Redux : `useApi` le garde dans les états
globaux, et il se lit par `useApi().user` (voir `Hooks/useApi`). L'ancienne
tranche `user` et ses actions ne sont plus exportées par le paquet.

## Pièges

- `globalState.reducers` doit être un objet stable (défini hors du
  composant, ou mémorisé) : un nouvel objet à chaque rendu recrée le store
  et perd son état.
- Une tranche nommée `global` dans `globalState.reducers` remplace celle de
  smartcommon et casse `useGlobalStates`.
- Pour modifier l'utilisateur connecté, écrire la clé `user` des états
  globaux avec le même stockage que `useApi` (voir `Hooks/useGlobalStates`),
  pas une tranche Redux.

Guide complet : `docs/provider.md` (sections "Schéma de montage" et
"Forme du `config`").
