## Installation

Le paquet est publié sur le registre npm d'inligit. Déclarer le registre dans
le `.npmrc` de l'application, puis installer :

```ini
@cap-rel:registry=https://inligit.fr/api/v4/projects/197/packages/npm/
```

```bash
npm install @cap-rel/smartcommon
```

## Démarrage

La feuille de style s'importe une fois, et `<Provider>` entoure toute
l'application : aucun composant ne fonctionne sans lui.

```jsx
import { createRoot } from "react-dom/client";
import { Provider } from "@cap-rel/smartcommon";
import "@cap-rel/smartcommon/dist/smartcommon-style.css";

import { App } from "./App";

// prefixUrl : l'API du module, relative à la PWA qu'il héberge.
const config = {
  api: { prefixUrl: "/api.php/" },
};

createRoot(document.getElementById("root")).render(
  <Provider config={config}>
    <App />
  </Provider>
);
```

## Traductions

Les textes des composants sont en anglais par défaut. Huit langues sont
livrées (`en`, `fr`, `de`, `es`, `it`, `pl`, `nl`, `pt`) et se passent par la
prop `labels` :

```jsx
import { LoginComponent, locales } from "@cap-rel/smartcommon";

<LoginComponent labels={locales.fr.LoginComponent} onSuccess={goHome} />
```
