# Timer

Champ de saisie de **durée** multi-unités (jours / heures / minutes /
secondes). Valeur sortie = nombre **entier de secondes**.

## Forme de la valeur

Entier secondes. Pas d'objet `{ d, h, m, s }` cote API. Conversion :

- secondes -> `{ days, hours, minutes, seconds }` :
  `secsToDuration(value)` exporté depuis `lib/utils`.

## Comportement

- **Cellules tappables + molette** : une cellule par unité visible ;
  taper une cellule ouvre un panneau ancré sous le champ avec une
  colonne défilante par unité (wheel picker tactile). Pas de clavier
  système. Fermeture au clic-extérieur ou via le bouton "OK".
- **Plages** : heures 0-23, minutes/secondes 0-59. Colonne Jours bornée
  à `maxDays` (sinon dérivé de `max`, sinon 0-99).
- **Pas de carry** entre unités : choisir une valeur n'entraine aucun
  débordement vers l'unité supérieure.
- **`showSeconds={false}`** masque la colonne Secondes et annule le
  résidu de secondes pré-existant lors d'une édition >= minute.

## Validation

`required` (valeur === 0), `min`, `max` (en secondes). Messages
incluent `formatDuration(seconds)` pour formater proprement la borne
dans le texte.

## Limites

- Pas de notation rapide "1h30" : sélection unité par unité.
- Pas de carry automatique entre unités.
- Pas de mode chronomètre live.
- Messages d'erreur en dur (pas extraits en `labels`).
- Pas de valeurs négatives.
- Colonne Jours bornée (`maxDays` / dérivé de `max` / 99).
