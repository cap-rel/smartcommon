# Gps

Champ qui capture la position GPS du device via
`navigator.geolocation`. Bouton "Localiser" → géolocalisation native,
valeur stockée comme `[latitude, longitude]`.

## Forme de la valeur

- Single (défaut) : `[lat, lng]` ou `null`.
- `multiple={true}` : `[[lat, lng], [lat, lng], ...]`.

## Comportement

- Bouton "Localiser" → `navigator.geolocation.getCurrentPosition`.
- Permission refusée → toast d'erreur "Echec de géolocatisation".
- **HTTPS obligatoire** (limitation browser).
- `onLocate(coords)` : callback optionnel en plus de `onChange`, pour
  les side effects (logging, appel API associé).

## Validation

Règle `required` intégrée. Message en dur "Vous devez géolocaliser."

## Limites
