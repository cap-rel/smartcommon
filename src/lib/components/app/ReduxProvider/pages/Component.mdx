# ReduxProvider

Creates the Redux Toolkit store of the app: the library reducers (global
states) merged with the ones of `config.globalState.reducers`, then provides it
to `react-redux`. Mounted by `<Provider>`, under `LibConfigProvider`, which it
reads.

```js
// config passed to <Provider>
const config = {
  globalState: {
    reducers: { cart: cartSlice.reducer },
  },
};
```

## Props

| Prop | Type | Role |
|---|---|---|
| `children` | node | The subtree. |
